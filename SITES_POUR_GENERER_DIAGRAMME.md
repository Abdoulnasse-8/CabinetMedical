# 🌐 Sites pour générer le diagramme PlantUML

## Sites recommandés pour visualiser PlantUML :

### 1. **PlantUML Online Server** (Le plus populaire)
🌐 **URL :** http://www.plantuml.com/plantuml/uml/
- ✅ Gratuit
- ✅ Pas d'inscription nécessaire
- ✅ Support complet PlantUML
- ✅ Export en PNG, SVG, PDF
- 📝 **Comment utiliser :**
  1. Ouvrez le fichier `diagramme_classe_plantuml.puml`
  2. Copiez tout le contenu
  3. Allez sur http://www.plantuml.com/plantuml/uml/
  4. Collez le code dans la zone de texte
  5. Le diagramme s'affiche automatiquement
  6. Cliquez sur "Download" pour télécharger en PNG ou SVG

### 2. **PlantText** (Interface simple)
🌐 **URL :** https://www.planttext.com/
- ✅ Gratuit
- ✅ Interface très simple
- ✅ Export direct en PNG/SVG
- ✅ Sauvegarde en ligne (optionnelle)

### 3. **PlantUML Editor** (VS Code Online)
🌐 **URL :** https://plantuml-editor.kkeisuke.com/
- ✅ Gratuit
- ✅ Éditeur avec aperçu en temps réel
- ✅ Export multiple formats

### 4. **PlantUML Viewer Chrome Extension**
- Extension Chrome pour visualiser PlantUML localement
- Utile si vous travaillez souvent avec PlantUML

---

## 📥 Méthode recommandée :

### Étape 1 : Générer le diagramme en image
1. Utilisez **PlantUML Online Server** (http://www.plantuml.com/plantuml/uml/)
2. Ouvrez le fichier `diagramme_classe_plantuml.puml`
3. Copiez-collez le contenu dans le site
4. Téléchargez l'image (PNG ou SVG)

### Étape 2 : Importer dans Lucidchart
1. Ouvrez Lucidchart
2. Créez un nouveau diagramme
3. Utilisez "Import" → "Image" pour importer l'image générée
4. OU créez le diagramme manuellement en utilisant `DIAGRAMME_CLASSE_COMPLET.md` comme référence

---

## 🎯 Alternative : Créer directement dans Lucidchart

Si vous préférez créer directement dans Lucidchart pour plus de flexibilité, suivez le guide `DIAGRAMME_CLASSE_COMPLET.md` qui contient toutes les instructions détaillées.
